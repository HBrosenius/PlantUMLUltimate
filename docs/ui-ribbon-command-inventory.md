# Ribbon command inventory

This is the migration inventory for `ui-ribbon-redesign-plan.md`. The ribbon calls existing document operations. Category selection changes only ribbon state. Command-palette IDs and keyboard routes remain stable; their category labels are search metadata, not workspace views.

Each row records an individual action. Repeated names belong to different diagram types or intentional secondary entry points. Fine-grained field editing, source completion and quick fixes remain in their existing editors and inspectors; they are not moved into the ribbon.

## Preserved secondary editing surfaces

Source selection keeps native Cut, Copy, Paste, Select all, Undo, Redo, search/replace, indentation and CodeMirror navigation. Diagram selection keeps its existing copy/paste/duplicate, delete, select-all and keyboard move semantics. Source symbol and class-member context menus, inline label editing, task-table editing and mobile sheets keep their original permission and selection guards. Problems, source repairs, import/export format choices, version-history actions, report export, Jira sync, presentation review, and project connection sub-actions stay within their existing dialogs; the table records their unchanged invoking destination.

Save errors and retry remain beside document identity. Dirty dots, project badges, connection state, participant count and linked-diagram sync-issue counts retain their existing live data. File export buttons explain rendering prerequisites. Insert and selection mutations explain read-only or missing-selection requirements. Plan remains a fixed category on every diagram type and explains its applicability on other types.

## Responsive and focus behaviour

The ribbon starts on Insert and expanded. At 1100px and below, command groups become named dropdowns. Document tabs and workspace views separate into rows at the same breakpoint. Categories support Left/Right/Home/End with roving focus. Dropdowns support Escape and outside dismissal. Creation dialogs use the shared focus trap and return focus to their invoking command; inspector close falls back to the selected ribbon tab if the original command is in a hidden category. Category, collapse and group-navigation controls do not trip inspector draft-leaving guards.
