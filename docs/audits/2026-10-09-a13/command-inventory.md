Recent commands store at most five IDs in browser storage. Each opening resolves IDs against current commands and excludes unavailable or disabled actions from the recent section. Search uses the current registry and shows each command once. Disabled commands remain in the full list and keyboard selection skips them. Storage failure does not prevent command execution.

Validation: all seven families' creation dialogs are opened through the palette in Chromium/Firefox/WebKit. Navigation coverage exercises document settings, history, Fit with source preservation, line navigation, semantic rename opening, Reports, tab activation/closing and context filtering of recents. Unit tests cover keyboard selection, disabled execution and recent-ID resolution. The desktop recent-command screenshot was inspected. Authenticated Jira/collaboration operations are outside this check; existing permission flags and handlers are reused.
