## Remaining work, classified

### Validation still pending in the repository records

- **Physical-device mobile testing:** A33 explicitly requires iOS Safari and Android Chrome with native keyboards, portrait/landscape, safe areas and accessibility checks. Browser emulation has passed but does not close this gate; see [device checklist](audits/2026-10-10-a33/README.md#real-device-completion-gate--pending).
- **Email-client compatibility:** Gmail web, Outlook variants and Apple Mail composed/received rendering remain unverified in [report implementation notes](reports-implementation.md#validation-and-compatibility). Clipboard/HTML tests do not establish received-mail behavior.
- **Human usability/project-review pilot:** [pilot protocol](project-review-pilot.md) exists; this review did not find a completed participant-results record. This is missing evidence, not proof the workflow is unimplemented or that nobody has tested it.
- **Current release verification:** existing runbooks and historical results are present. This review did not rerun the full browser/PWA/collaboration matrix or inspect current CI, production configuration, branch protection or logs. The user confirmed the recent Jira connection flow works on 2026-10-11; that does not establish every failure/reload/publishing path.

### Remaining implementation from the reliability plan

`apps/collaboration-worker/src/index.ts` bounds document/update/body sizes, but has no application-level room-creation/message rate limiter, connection cap or idle-room alarm/retention implementation. `apps/integration-worker/src/index.ts` bounds JSON and performs expired-state cleanup through request-triggered `ctx.waitUntil`; it has no scheduled cleanup handler or application-level request rate limiter. Infrastructure-level limits were not inspected, so their absence is not claimed. These are the remaining service-boundary tasks from September, not a new defect report. Retention work must preserve revocation guarantees.

### Deliberately deferred or narrowed scope

- **Reports:** weekly digest, dedicated lookahead/data-quality templates, dependency handoffs, WBS/scenario reports, portfolio, saved packs, scheduled delivery, cost and response tracking remain optional extensions. Task equivalents are implemented; duration weighting is not. Milestone outlook does not itself include forecast dates; Progress forecast is a separate report.
- **Scenarios (updated 2026-10-12):** bounded alternatives are now embedded in standalone and multi-diagram `.pumlu` files and workspace backups, with legacy browser-local migration. Live sharing, branch ancestry and simultaneous multi-alternative comparisons remain deferred. See the [portable scenario follow-up](delivery-scenario-lab-plan.md#portable-scenario-follow-up--2026-10-12).
- **Review:** A31 is single-document review; multi-file acceptance/global semantic identity remain deferred. A32 provides personal browser-local anchored notes; shared comments/review links are a separate extension.
- **UI proposals:** delivery records resolve competing proposals and intentionally narrow some requests. For example, A22 keeps dependencies/resources/notes in task-specific flows. Do not reopen rejected alternatives as missing features.
