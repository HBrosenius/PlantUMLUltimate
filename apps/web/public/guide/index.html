How to use the online PlantUML editor

  1. Open the editor and choose a diagram type. If you already have a workspace open, use the new diagram tab button.
  2. Choose Code or Split view to edit the PlantUML source. You can start with one of the examples below.
  3. Use Add to insert elements, or select supported elements in the preview to edit their properties. The source and diagram stay in sync.
  4. Use Save for a portable document, or File → Export for a diagram image.

The editor supports Sequence, Class, Component, Use Case, Activity, Gantt and WBS diagrams. Use sequence diagrams for interactions, class and component diagrams for structure, and activity diagrams for workflows. Gantt charts describe schedules; WBS diagrams break a project into deliverables.

PlantUML examples to try

Create a diagram of the matching type, then replace its source with the example. Edit a label and watch the preview update.

Sequence diagram: a request and response

Sequence diagrams show messages between participants over time. This example describes a user requesting a page from a system. 

@startuml
actor User
participant System
User -> System: Request page
System --> User: Show page
@enduml

Gantt chart: a small project schedule

Gantt charts show task durations and dependencies. Here, implementation starts after design finishes.

@startgantt
Project starts 2026-11-02
[Design] lasts 3 days
[Implement] lasts 5 days
[Implement] starts at [Design]'s end
@endgantt

WBS diagram: break down a release

A work breakdown structure organizes deliverables into a hierarchy. Add another asterisk to place an item one level deeper. 

@startwbs
* Release
** Design
*** Wireframes
*** Review
** Implementation
** Testing
@endwbs

For additional syntax, see the official PlantUML documentation. For tool-specific actions, open More → Help in the editor.

Save editable documents and export images

Save your work as a .pumlu document to retain diagrams, history and settings. Export SVG for scalable diagrams or PNG for a raster image you can place in a document or presentation.

Browser recovery helps restore your workspace on the same browser. It is separate from saving a file: keep a saved document or workspace backup for work you need to retain.

Common questions

Do I need a PlantUML server?

No. Diagram rendering runs locally in your browser. Core editing and image export do not require a PlantUML server.

Can I use the editor offline?

The app supports offline startup after its resources have downloaded. Online features such as live collaboration and Jira integration still need a connection.

Can I edit both the source and the diagram?

Yes. Code, Split and Diagram views let you choose how to work. Visual controls vary by diagram type; source editing remains available for PlantUML syntax beyond those controls.

Does my diagram leave my device?

Rendering happens in the browser. If you choose live collaboration or an external integration, those features communicate with their services. Browser recovery and saved files are separate from collaboration.
