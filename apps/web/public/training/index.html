LEARN AT YOUR OWN PACE

From your first diagram
to a working project.

Current controls: Canvas zoom magnifies the drawing; Time axis changes the Gantt schedule display. Earlier videos call these preview zoom and timeline scale. In the creation dialog, select a type or example, then choose Create diagram. Property updates change the diagram; Save writes the file.

Nineteen guided lessons cover planning, modeling and the everyday workflow. Pause, practice and return to any chapter.
